# 机器人概论：自动编程作业

本目录包含两项可独立运行的作业、AI 编程指导过程、设计与验收说明、测试及运行脚本。原始题目保留在《自动编程作业(1).docx》。代码使用 Python 标准库，无需 pip 安装依赖，无外部数据集。

## 运行

在本目录打开终端，使用 Python 3.9 或更新版本：

```powershell
python 模块1/main.py
python 模块2/main.py
```

Windows 一键运行两个示例和全部测试：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\run.ps1
```

这里的 ExecutionPolicy 参数只用于当前进程，不修改系统配置。Linux/macOS 使用 `bash run.sh`，要求 python3 可用。

也可分别运行测试：

```powershell
python 模块1/test_homework.py
python 模块2/test_homework.py
```

不要使用 Python 的 -O 选项运行验收示例，否则主程序中的 assert 会被关闭。自动测试使用 unittest 的断言。

## 预期结果

- 作业 1：先按题目要求把 8 个网格动作翻译为 10 条机器人指令，再输出朝向感知规划的 9 条最优指令。三种执行均到达 (4,4)，并显示节省的指令数。
- 作业 2：先打印初始地图，再在每一步执行并记录后打印累计轨迹地图，共 9 张地图（初始 1 张＋逐步 8 张）。最后打印完整轨迹、步数、规划次数和搜索节点统计；默认终点 (4,4)，8 步，仅规划 1 次。地图连续追加，不清屏、不暂停。
- 默认轨迹：(0,0) → (0,1) → (0,2) → (0,3) → (0,4) → (1,4) → (2,4) → (3,4) → (4,4)。
- 作业 2 地图符号：A 为智能体，S 为起点，* 为已走位置，G 为目标，# 为障碍，. 为未走空地；初始时 A 覆盖 S，到达目标时 A 覆盖 G。作业 1 保持原有实现。
