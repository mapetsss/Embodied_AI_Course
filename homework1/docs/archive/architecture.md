# 软件架构与算法说明

## 模块边界

两项作业分别保存 env.py 和 planner.py，便于独立提交与执行。规划器相同，作业 2 的环境额外支持累计轨迹显示；后续若扩展成一个项目，可再提取公共包。

| 模块 | 输入 | 输出或状态变化 |
|---|---|---|
| env.py | 网格动作 | 更新位置、步数；提供通行判断及字符地图 |
| planner.py | 环境或地图快照 | 网格动作列表、空列表或 None；不改变环境 |
| homework1/translator.py | 网格动作、初始朝向 | 机器人指令列表 |
| homework1/robot.py | 机器人指令 | 更新自身朝向及环境位置，独立统计指令数和前进次数 |
| homework1/robot_planner.py | 环境、初始朝向 | 最少机器人指令列表、空列表或 None；可返回搜索状态统计 |
| homework2/agent.py | 环境、执行上限 | 调度循环，返回记忆总结 |
| homework2/memory.py | 实际状态转换 | StepRecord 列表、轨迹和动作总结 |
| main.py | 默认场景 | 执行、打印、断言验收结果 |

## 数据流

作业 1 基础流程：环境 → 网格 BFS → 网格动作 → 翻译 → 机器人执行。另用一份独立环境执行原始网格动作，再比较两个终点。机器人执行器直接用朝向对应的位移，不调用翻译函数，避免用同一套转换逻辑自我验证。

作业 1 优化流程：环境＋初始朝向 → 朝向感知 BFS → 最少机器人指令 → 独立机器人执行器验证。优化结果单独输出，不替代题目要求的网格动作翻译结果。

作业 2：地图快照 → 检查缓存路径 → 必要时 BFS → 执行第一个动作 → env.step → Memory.record → 下一轮。快照复制当前位置、目标、动作表和障碍集合，规划不持有可修改的实时环境状态。当前位置已到目标时直接结束。静态地图复用剩余路径；若下一步因新增障碍而失效，智能体根据最新快照重新规划。

逐步显示：`Agent.run(max_steps=100, on_step=None)` 在每次记忆写入后调用可选的 `on_step(record, summary)`。主程序先打印初始地图，再在回调中调用 `env.render(trajectory=..., start=...)`。环境仅绘图，智能体不负责终端输出；不传回调时仍可直接运行原有逻辑。最后一步已显示终点地图，汇总时不重复绘图。轨迹列表来自实际记忆，显示时转换为集合判断访问状态，不修改原轨迹。

## 算法

BFS 按 up、down、left、right 的顺序扩展相邻格点，排除 stay、越界、障碍和已访问点。各条边权重相等，因此首次找到终点时获得最少移动步数。

默认路径为连续四次 up，再连续四次 right。起终点曼哈顿距离为 |4-0|+|4-0|=8，该路径恰有 8 步，所以是最短路径。

朝向编码为 N=0、E=1、S=2、W=3。设当前编码为 h、目标方向为 t，差值 d=(t-h) mod 4。d=0 不转，d=1 右转，d=2 两次右转，d=3 左转，然后前进一步。

朝向感知规划把状态定义为 `(position, heading)`，边分别对应 `forward`、`turn_left` 和 `turn_right`，每条边成本均为 1。BFS 首次到达目标位置时得到最少指令数。默认场景至少需要 8 次 forward；机器人初始朝东，而目标相对起点同时向东、向北，因此至少转向一次，下界为 9 条指令。算法找到 `forward × 4 → turn_left → forward × 4`，达到该下界，所以结果最优。

计数区分：GridWorld.steps 为网格动作尝试次数；Robot.command_count 为全部机器人指令次数；Robot.forward_count 为前进尝试次数。Robot 不更新 GridWorld.steps，机器人演示使用自己的计数器。

## 性能与限制

基础 BFS 图遍历复杂度为 O(V+E)。队列只保存位置，`parents` 字典为每个已发现位置记录“前驱位置＋到达动作”；首次发现终点后反向回溯并翻转动作列表。搜索复杂度为 O(V+E)，额外空间为 O(V)，回溯路径长度为 O(L)。

智能体保存当前规划中尚未执行的动作。默认静态地图从原先每步规划一次的 8 次降为 1 次；每轮仍然感知并验证下一步，兼顾路径复用和动态障碍。统计采用规划调用次数、展开节点数和发现节点数，避免仅用小地图的毫秒耗时作结论。作业 1 的朝向感知规划最多搜索 `4V` 个“位置＋朝向”状态，时间和空间复杂度仍随状态图线性增长。
