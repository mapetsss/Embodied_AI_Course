# MASt3R-SLAM 基线与 A 模块

本目录保存基于 [MASt3R-SLAM](https://github.com/rmurai0610/MASt3R-SLAM) 的基线兼容补丁、A 模块代码及实验分析脚本。固定上游提交为 `e6f4e3d474fad0e11f561482012be864ba8c3f17`。不包含模型、数据集、运行环境或实验采集数据。

- `baseline/`：基线 CUDA、PyTorch 兼容补丁及 Python 约束；运行需要上游源码、依赖和模型。
- `original-a001/`：原始冻结版 A 的六个文件、补丁、实现说明和发布清单；原始两序列各三模式实验对应此版本。
- `current/`：本地精简后的代码增量。`changes.patch` 相对上述上游提交；新增的 `reliability.py` 与三个配置文件单独存放。此版本尚未重新发布或完成真实 GPU/SLAM 验证，不能将 a001 的实验结果直接归属给它。
- `analysis-tools/`：采集、第四轮分组干预和第五轮机制分析的核心脚本。它们依赖未包含的采集输入、标注、目标机环境和其他工作流文件，不能仅凭此目录独立复现实验。

A 是已知标定、双视图前端可靠性与加权重估原型。原始跟踪初估后，利用同次推理描述子构造固定权重，尝试有限步重估，检查失败时回退。B 和地图保护 P 尚未实现。详细设计见 `original-a001/IMPLEMENTATION.md`。

原始实验中，desk 和 walking_xyz 的单次对照没有显示明确的最终 ATE 收益，weighted 总耗时分别增加约 4.31% 和 4.42%。第四、五轮结果因区域与指标而异，尚不足以选择统一的算法修改。第五轮是复用已有输入的探索性诊断，不是独立泛化验证。

上游 MASt3R-SLAM 许可见 `UPSTREAM-LICENSE.md`；其依赖、模型和数据集可能适用各自的许可。
